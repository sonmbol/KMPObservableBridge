# Support

Use [GitHub Discussions](https://github.com/sonmbol/KMPObservableBridge/discussions)
for setup questions, architecture advice, integration examples, and ideas.

Use [GitHub Issues](https://github.com/sonmbol/KMPObservableBridge/issues) for
reproducible defects and accepted feature work. Include the package version,
toolchains, integration mechanism, and a minimal reproduction.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and should not
be disclosed in a public issue.
